Day 31: Ứng dụng quản lý công việc (REST API Todo App)

Xây dựng ứng dụng gọi API bất đồng bộ để quản lý công việc, thay thế hoàn toàn cơ chế lưu trữ localStorage cũ bằng hệ thống cơ sở dữ liệu mock qua json-server.

  • Project Bắt Buộc

    REST API Todo App - json-server Full CRUD

    Ứng dụng thực chiến áp dụng trọn vẹn mô hình CRUD (Create, Read, Update, Delete) bằng Fetch API và Async/Await. Tích hợp đầy đủ các cơ chế đồng bộ nâng cao: Thêm mới dữ liệu (POST), cập nhật nội dung (PUT), lật ngược trạng thái công việc (PATCH), xóa dữ liệu an toàn (DELETE), kết hợp bộ lọc Tab trạng thái và tìm kiếm thời gian thực (Real-time Search).
